TEMPLE RUN 3D — JUNGLE ESCAPE
=============================

GitHub Pages-ready browser game. This is a complete self-contained project;
the 3D world, runner, coins, jungle props and obstacles are generated in code.

UPLOAD TO GITHUB
1. Extract this ZIP.
2. Upload index.html, style.css, README.txt and the js folder to the ROOT of your repository.
3. In GitHub: Settings → Pages → Deploy from a branch → select main and /(root) → Save.
4. Open https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/

CONTROLS
Desktop: Left/Right arrows or A/D to change lanes; Up/Space/W to jump;
Down/S to slide; Escape pauses/resumes.
Mobile: swipe left/right/up/down or use the on-screen controls.

NOTES
- Three.js r128 is loaded from a CDN, so an internet connection is required.
- No external GLB model or paid asset is required. The runner and environment
  are procedural 3D models with physically based materials and real-time lighting.
- For best performance, use a modern browser with WebGL enabled.
- To embed in Blogger, use an iframe pointing to the GitHub Pages index.html.
